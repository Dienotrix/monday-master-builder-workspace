## Conventions and deviations worth knowing

- The key uses two of the calibration statuses, `met-with-residual` and `not-obtainable`, and the per-criterion `asked` flag. It does not exercise `advisory`, because the type resolves cleanly; no calibration fixture carries a positive `advisory` row, because every fixture's type resolves; the value's positive case is the constructed unresolvable fragment of BUILD-PLAN.md section 4.3, item 8 (H50).
- The read-back grade lives in `intake.structure_inventory.read_back.grade` and is named in `expected_verdict.gates_met`; it is not a rubric row, so the rubric keeps the spec's criterion names only.
- `numbers.bleed.status` is `met` (the reviewed vocabulary) while the R4 row is `met-with-residual`; the value text explains the residual. `numbers.upside.quote` is null with status `missing`, following s22 for a not-obtainable item.
- `expected_structures.native_boards_required` is an empty array, with the reason in `notes`.
- Every list entry is printed on one line and scalar-only objects are printed on one line, the layout that kept the key under the stage-1 400-line budget; the fix pass keeps the layout and the `readiness` block takes the file to 569 lines.
- Call types and the type header use the tokens `shared/record-map.md` pins for the type header (the ARCHITECTURE.md 8.3 step 5 values in their hyphenated form, with the fixture's reasoning in a `_note` beside each field) and the labels of 7.1 verbatim.
- Tool references are category words throughout, and no sentence in the transcript, the key or this file names more than one category. monday is named because the product is monday.
- Dates are relative and fit October 2026: the call in the week of Monday 12 October (Noor's first week group is 19 October), the working session Tuesday 20 October at 7:30 Eastern, the owner's yes wanted before Thanksgiving (26 November), the first Copperline store the week of Monday 11 January 2027, done by end of March. No transcript states its own date.
- Names narrated on the client's screens (customers, cities, job numbers, crew leads) are current-state facts and carry no `[X]`; the key asserts the absence of quarantine in one line.
- Real places (Grand Rapids, Fort Wayne) are named on purpose, as the reviewed fixtures do; every organisation, person, figure and date is invented, and no name collides with another fixture's (s25 has a person called Marlowe; s19's Marlow is a city, spelt differently, and the exact-match collision scan passes).
