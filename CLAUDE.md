# monday Master Builder: development workspace

**Scope of this file (A22).** These instructions apply to sessions opened in this project folder (`~/DelOps/monday-master-builder-dev/` on the Mac, wherever it is cloned on Windows) or in its development folders: `monday-master-builder/`, `rebuild-workspace/` and `for-review/`. A session opened inside this folder's `clients/` is a client session: ignore this file entirely, read nothing in this project folder outside the client's own folder and the plugin's shared home folders, and never open or edit `HANDOFF.md`.

This folder holds the monday Master Builder build: the product repo (`monday-master-builder/`), the design and research working material (`rebuild-workspace/`), and the user's review folder (`for-review/`).

**Start every session by reading `HANDOFF.md` in this folder.** It carries the objective, the authority order, the standing rules, the cost policy and the current state. The user's decisions live in `rebuild-workspace/design/AMENDMENTS.md` and override every other document.

Non-negotiables, in one line each: "the user", never a personal name; no monday account named and no references to earlier work anywhere, because the plugin must work for whoever uses it; nothing from the deleted real client calls; nothing copied from any earlier plugin; neutral names in anything written into monday; no live monday writes until the user names a test workspace, and no account ids in project files; the three A11 decisions stay open; no AI-credit pricing; commit only when asked.
